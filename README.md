# Automations - Client Sophie

## Scénarios
1. Gmail → Notion : classification des mails clients
2. Gmail → Notion : détection absences/retards
3. Docage → Notion : statut des contrats
4. Boîte mail → Notion : dates newsletters
5. Notion → Export Excel
6. Tally + Calendly : liste d'attente
7. Mails → Drive : récupération factures

## Installation
- Python 3.12
- Environnement virtuel : venv/
- Dépendances : pip install -r requirements.txt

## Configuration
Remplir le fichier .env avec les clés API
